# Font Files Required

Place the following font files in this directory:

## Perandory
- `Perandory-Regular.otf`
- `Perandory-Bold.otf`
- `Perandory-ExtraBold.otf`

## Burgues Script
- `BurguesScript.otf`

## Lora
Lora is loaded from Google Fonts automatically — no local file needed.

## Notes
- The @font-face declarations are in `src/styles/index.css`
- If the font file names differ slightly, update the `src` paths in the @font-face declarations
- Until these files are placed, the site will fall back to Outfit (headings) and Georgia/serif (script)
